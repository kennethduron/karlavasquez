# FUTURE_SUPABASE_REFERENCE

Las migraciones SQL de este directorio pertenecen a la Phase 0 y se preservan para una posible migración futura a Supabase/PostgreSQL.

No son el backend actual, no deben ejecutarse como parte de los scripts Firebase, no controlan Auth/Storage/permisos vigentes y no implican una decisión de despliegue. Consulte `docs/FUTURE_SUPABASE_MIGRATION.md`.
